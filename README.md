ember is a local-first desktop app that reads your own Claude Code data from
`~/.claude`, turns it into usage insights and a "personal style" profile, lets
you package that profile to carry between machines, and lets you manage and run
multiple Claude Code configurations side-by-side. Everything runs on-device by
default — nothing is uploaded.

## Features

- **Dashboard** — usage insights from your session transcripts: tokens (input/
  output/cache), models, activity by hour, per-project breakdown, tool usage.
- **Profile** — a deterministic "how you work" profile (archetype + trait cards)
  derived from your data, with on-device communication heuristics. Includes an
  optional **Narrative**: an LLM-written prose version of your profile using a
  **provider-agnostic, OpenAI-compatible** backend — point it at a local model
  (Ollama, oMLX, LM Studio, llama.cpp) or any OpenAI-compatible endpoint.
- **Portable** — export a re-importable bundle of your setup (style profile,
  `skills/`, `settings.json`, `CLAUDE.md`) with **credentials excluded**, and
  apply it to another machine.
- **Profiles** — manage multiple isolated Claude Code configurations (each its
  own `CLAUDE_CONFIG_DIR`) and **launch one — or several side-by-side** — in a
  terminal, without ever touching your real `~/.claude`. Create profiles blank,
  by cloning, or from a bundle, and edit key settings (model, permission mode,
  enabled plugins, `CLAUDE.md`) in-app.

## Privacy

- Reads your local `~/.claude` only; **credentials are never read or exported**
  (`.claude.json`, `.credentials.json` are excluded everywhere).
- The narrative feature is **local-first** — with a local model nothing leaves
  your machine; any optional cloud API key is stored in the macOS **Keychain**,
  never on disk. The UI flags when a non-local endpoint is configured.
- Profile management never modifies `~/.claude` — profiles are separate config
  directories.

## Tech stack

[Tauri 2](https://tauri.app) (Rust backend) + [Vue 3](https://vuejs.org) + Vite +
TypeScript. Charts are hand-rolled SVG (no chart dependency).

## Requirements

- **macOS** (the backend uses the macOS Keychain and an `osascript` launcher).
- [Node.js](https://nodejs.org) 20+ and [Rust](https://rustup.rs) (stable).

## Develop

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```

Produces `src-tauri/target/release/bundle/macos/ember.app` and a `.dmg`. Builds
are unsigned — for sharing internally, recipients can right-click → Open, or
clear the quarantine flag: `xattr -dr com.apple.quarantine /Applications/ember.app`.

## Project layout

```
src/                  Vue frontend
  views/              Dashboard / Profile / Portable / Profiles
  components/         charts, cards, editor, narrative panel, …
  lib/api.ts          typed wrappers over Tauri commands
src-tauri/src/        Rust backend
  claude_data.rs      ~/.claude transcript scan + usage aggregation
  profile.rs          deterministic style profile
  narrative.rs        provider-agnostic LLM narrative
  portable.rs         profile bundle export / import
  profiles.rs         multi-config management + launch
design/icons/         app icon, drafts, and ICON.md (how it was made)
```
