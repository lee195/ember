## Capturing them (macOS)

1. Run the app: `npm run tauri dev`
2. For each tab, capture just the ember window:
   - **Cmd + Shift + 4**, then tap **Space**, then click the ember window, or
   - **Cmd + Shift + 5** → _Capture Selected Window_.
3. Save/rename each to the filename above and move it into this folder.

Tip: a consistent window size across shots looks best. Retina captures are ~2×;
that's fine — GitHub/Forgejo scale them down.
