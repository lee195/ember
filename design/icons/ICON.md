# ember app icon

**Locked-in icon:** [`ember-mascot-orbit-astronaut.svg`](./ember-mascot-orbit-astronaut.svg)
→ rasterized to `ember-icon-1024.png` → generated into `../../src-tauri/icons/`
(referenced by `bundle.icon` in `src-tauri/tauri.conf.json`).

![icon](./ember-icon-1024.png)

## Concept

ember's identity is a **glowing ember** (the app's warm accent `#ff7a45` on a dark
UI, echoing the 🔥 in-app logo). For the icon that ember became a **friendly
mascot in space**: a glowing ember "planet" with a face, an orbit ring, a tiny
helmeted **ember-naut** buddy riding the orbit, a faint motion trail, and a few
stars/sparkles. It's warm and characterful while still reading clearly at small
sizes, and the orbit quietly nods to the app's "sessions / portable profile" idea.

## Design choices

- **Frame:** macOS-style squircle (rounded rect, `rx 116` on a `512` viewBox) with
  transparent corners — shown as-is by macOS.
- **Background:** deep-space diagonal gradient (`#1d2038 → #0c0d15`).
- **Ember body:** warm radial "coal" gradient — cream `#fff3cf` → amber `#ffb14a`
  → orange `#ff6a32` → red `#c8301f` — with a soft `#ff7a45` halo behind it.
- **Face:** dark-warm `#3a1206` eyes/smile with cream highlights and translucent
  `#ff5630` cheeks.
- **Space accents:** icy blues for the orbit/helmet (`#7e8ff0`, `#9fb0ff`,
  `#cfe0ff`) to contrast the warm ember; warm `#ffd16b` sparkles + ember-toned
  motion-trail dots.

## How it was made

**All icons were generated by Claude (Claude Code).** They were produced as
hand-authored SVG — every shape is a path, gradient, or primitive written
directly in markup by the model, not via a raster/diffusion image generator — so
they're infinitely scalable and easy to tweak. Previews and the final raster were
produced with `rsvg-convert`; the platform icon set with the Tauri CLI.

Iteration is preserved as drafts in this folder:

| Stage | Files |
|---|---|
| Static marks | `ember-flame.svg`, `ember-bars.svg`, `ember-coal.svg` |
| Coal → mascot | `ember-mascot-orbit.svg`, `ember-mascot-comet.svg` |
| Orbit riffs | `ember-mascot-saturn.svg`, `ember-mascot-astronaut.svg`, `ember-mascot-sleepy.svg`, `ember-mascot-data.svg` |
| **Final** | **`ember-mascot-orbit-astronaut.svg`** (orbit mascot + mini ember-naut + motion trail + sparkles) |

`ember-mascot-sleepy` and `ember-mascot-astronaut` also make good secondary art
(empty states / about screen) if needed later.

## Regenerating the icon set

```bash
# 1. rasterize the source SVG to a 1024×1024 PNG
rsvg-convert -w 1024 -h 1024 design/icons/ember-mascot-orbit-astronaut.svg \
  -o design/icons/ember-icon-1024.png

# 2. generate the platform icons into src-tauri/icons/
npm run tauri -- icon design/icons/ember-icon-1024.png
```

Notes:
- `src-tauri/icons/` is committed (un-ignored in `.gitignore`) so the icon ships
  with builds.
- The Tauri CLI also emits iOS/Android icons; they were removed since ember is a
  macOS desktop app. Re-run the command if mobile targets are ever added.
